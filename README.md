# claude-mods

Mods for Claude Code.

| Mod | What it does |
| --- | --- |
| [tok-speedo](./tok-speedo) | A tokens-per-second speedometer on the status line, with a running average and trend |

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install tok-speedo --marketplace thehumanworks/claude-mods
```

Answer `y` to add the marketplace, then pick a scope (user scope loads it in every session).

From a shell:

```
claude plugin install tok-speedo --marketplace thehumanworks/claude-mods
```

In the desktop app: click **+** next to the prompt box → **Plugins** → **Add marketplace** with `thehumanworks/claude-mods`, then **Add plugin**.
